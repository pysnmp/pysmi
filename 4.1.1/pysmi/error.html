Exceptions¶

Every error PySMI raises derives from PySmiError, so a caller that has no interest in which stage failed can catch that one class.

The stages raise their own subclasses. A searcher reports that a MIB need not be compiled by raising PySmiFileNotModifiedError or PySmiFileNotFoundError; a reader reports the same conditions about a source file with PySmiReaderFileNotModifiedError and PySmiReaderFileNotFoundError. Those are part of the normal flow of a compilation run, not failures.

exception pysmi.error.PySmiError(*args: object, **kwargs: object)¶

Base class for every error PySMI raises.

Subclasses identify which stage failed. Catch this to catch them all.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

__getattr__(name: str) → Any¶

Report the context attributes handlers attach as they re-raise.

Attributes are set from keyword arguments, so which ones exist depends on where the error came from and who handled it on the way up. Missing ones still raise AttributeError, as they always did.

__repr__() → str¶

Spell out every context attribute that was actually set.

__str__() → str¶

Report the message alone, leaving the context to __repr__.

file: str¶

MIB file the error concerns.

handler: Any¶

Component that was handling the MIB when it failed.

mibname: str¶

MIB module the error concerns.

msg: str¶

The error message. Handlers extend it as the error travels up the stack.

reader: AbstractReader¶

Reader the MIB was being fetched from.

searcher: AbstractSearcher¶

Searcher that was consulted.

source: AbstractReader¶

Reader that supplied the MIB, as recorded by the compiler.

writer: AbstractWriter¶

Writer that was storing the MIB.

Lexer and parser¶

exception pysmi.error.PySmiLexerError(*args: object, **kwargs: object)¶

A MIB could not be broken into tokens.

Raised for input the SMI grammar forbids outright: a reserved word used as an identifier, or an identifier ending in a hyphen.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

__str__() → str¶

Report the message with the source line the offending token came from.

lineno: int | str = '?'¶

Line the offending token was read from, or “?” when it is not known.

exception pysmi.error.PySmiParserError(*args: object, **kwargs: object)¶

A MIB tokenised but did not parse.

Raised when the token stream does not fit the grammar. Carries the line number of the offending token, inherited from PySmiLexerError.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

exception pysmi.error.PySmiSyntaxError(*args: object, **kwargs: object)¶

A more specific parse failure.

Nothing in PySMI raises this; it exists so callers can distinguish a syntax error from other parser errors should a parser start reporting one.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

Searcher¶

exception pysmi.error.PySmiSearcherError(*args: object, **kwargs: object)¶

A searcher could not determine whether a compiled MIB is current.

Raised when the stored MIB exists but cannot be examined – unreadable file, or an unparsable timestamp in a compiled module.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

exception pysmi.error.PySmiFileNotModifiedError(*args: object, **kwargs: object)¶

The compiled MIB is already up to date.

Not a failure: searchers raise it to tell the compiler it can skip this MIB, and the compiler marks the module untouched.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

exception pysmi.error.PySmiFileNotFoundError(*args: object, **kwargs: object)¶

No usable compiled MIB was found.

Raised when nothing is stored for the module, or what is stored is older than the source and must be rebuilt.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

Reader¶

exception pysmi.error.PySmiReaderError(*args: object, **kwargs: object)¶

Base class for failures fetching MIB source.

Nothing raises this directly; catch it to catch any reader failure.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

exception pysmi.error.PySmiReaderFileNotModifiedError(*args: object, **kwargs: object)¶

The MIB source is older than the caller asked for.

Raised when a reader is given a modification time to beat and the source it found does not beat it.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

exception pysmi.error.PySmiReaderFileNotFoundError(*args: object, **kwargs: object)¶

A reader has no source for this MIB.

Every source is tried in turn, so this is the ordinary “not here, try the next one” signal; it only reaches the caller when no source has the MIB.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

Code generator¶

exception pysmi.error.PySmiCodegenError(*args: object, **kwargs: object)¶

A code generator could not produce output for a MIB.

Raised when generation reaches an unusable state – a symbol left without generated code, or an existing MIB index that cannot be read back.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

exception pysmi.error.PySmiSemanticError(*args: object, **kwargs: object)¶

A MIB parsed but does not mean anything consistent.

Raised for a MIB that is syntactically valid yet self-contradictory: a duplicate symbol, a second module identity, or a reference to a module absent from the symbol table.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

Writer¶

exception pysmi.error.PySmiPatchError(*args: object, **kwargs: object)¶

A MIB patch is not a well-formed unified diff.

Raised for an unreadable line or hunks that run backwards. A patch whose context does not match the text it is offered is not this: that is the ordinary case of text the patch was not cut against, and it is reported as NOT_APPLICABLE rather than raised.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.

exception pysmi.error.PySmiWriterError(*args: object, **kwargs: object)¶

Generated output could not be stored.

Raised when the destination cannot be created or written, or when a caller-supplied callback raises while receiving the output.

Record the message and whatever context the caller attaches.

The first positional argument becomes msg. Every keyword argument is set as an attribute, which is how handlers annotate an error with the MIB, reader, or writer involved as it travels up.
