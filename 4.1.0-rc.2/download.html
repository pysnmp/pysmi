Download & Install¶

The SNMP SMI library is published to PyPI as pysnmp-pysmi. Note the name: pysmi is the original, unmaintained package.

With uv:

$ uv add pysnmp-pysmi

Or with pip:

$ python -m venv venv
$ source venv/bin/activate
$ pip install pysnmp-pysmi

Either way you also get the mibdump and mibcopy command-line tools. To run them without installing anything permanently:

$ uvx --from pysnmp-pysmi mibdump --help

PySMI needs Python 3.10 or newer.

Alternatively, you can download the latest release from GitHub or PyPI.
